Issue 8: rule failures are treated like passes
Status: Critical and unresolved.
BaseAgent.run() and dynamic rule execution catch exceptions and return empty findings.
Therefore:
Rule query fails → zero findings → compliance score may increase
That is unsafe.
Required behaviour:
A failed rule must become NOT_ASSESSABLE or make the run fail.

Compliance score must not count failed rules as satisfied.
